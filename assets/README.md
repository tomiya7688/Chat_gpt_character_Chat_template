# assets

このディレクトリには、キャラクターチャットで参照させたい画像資料を置きます。

## 例

```text
assets/
├── README.md
├── character-a.png
├── character-b.png
└── character-a-expression-smile.png
```

ファイル名は、どのキャラクターの画像か分かる名前にしてください。

## CHARACTERS.md から参照する

画像を追加したら、対応するキャラクター設定にパスを書きます。

例：

```markdown
## ミナ

### キービジュアル

![ミナ](assets/mina.png)

この画像をミナの外見・配色・服装の基本資料として扱う。
```

## AIにどう扱わせるか

画像は主に次の情報の参考資料として使います。

- 顔・身体の形
- 髪型
- 色
- 衣装
- 身につけている物
- 全体的なデザイン

性格、一人称、口調、知識、関係性などは画像から推測させず、`CHARACTERS.md` の文章設定を正本にしてください。

画像から読み取れない部分を、AIが重要設定として勝手に確定しないようにします。

## 複数画像がある場合

必要なら、

```text
assets/
├── character-a/
│   ├── main.png
│   ├── smile.png
│   └── winter-clothes.png
└── character-b/
    └── main.png
```

のようにキャラクターごとに分けても構いません。

どの画像が基本デザインなのかは、`CHARACTERS.md` に明記してください。

## 注意

GitHubのURLだけをChatGPTへ渡す方式では、利用環境によって画像そのものを取得・確認できない場合があります。

その場合でも会話が成立するよう、重要な外見設定は画像だけに依存せず、`CHARACTERS.md` に文章でも書いておくことをおすすめします。
