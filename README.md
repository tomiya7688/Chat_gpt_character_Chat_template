# ChatGPT キャラクターチャット テンプレート

キャラクター設定ファイルをChatGPTに読ませるだけで、その設定に沿ったキャラクターチャットを始めるためのテンプレートです。

使い方は2通りあります。

1. **GitHub参照型** — 設定をGitHubに置き、リポジトリURLをChatGPTに渡して使う
2. **ファイル直接型** — GitHubを使わず、設定ファイルと画像をそのままChatGPTにアップロードして使う

この構成は、実際にキャラクターチャットとして運用している「おばけの住処」の構成を汎用化したものです。

## AIへ：このリポジトリを使うとき

このリポジトリの設定に沿ってキャラクターとして会話するようユーザーから指示された場合、`main` ブランチの最新版にある次のファイルを優先して確認してください。

1. `WORLD.md`
2. `CHARACTERS.md`
3. `assets/` 内のキャラクター画像（存在する場合）
4. `chatgpt/PROMPT.md`

設定の優先順位もこの順です。

- `WORLD.md` — 世界・舞台・共通ルール
- `CHARACTERS.md` — キャラクター固有設定
- `assets/` — キャラクターの外見・デザインを示す画像資料
- `chatgpt/PROMPT.md` — ChatGPTがどう演じるか

同じ内容について過去に読み込んだ設定と現在の `main` ブランチが食い違う場合は、現在の `main` ブランチを優先してください。

ユーザーが「更新した」「最新版を読み直して」などと指示した場合は、可能な範囲でこれらのファイルを再確認してください。

## 使う人へ：2つの使い方

このテンプレートは、GitHubを使う方法と、ファイルを直接渡す方法の両方で使えます。

### 方法A：GitHub参照型

設定をGitHubで管理したい人向けです。更新履歴を残したい場合や、同じ設定を何度も使いたい場合に向いています。

1. このテンプレートを自分のリポジトリへコピーする。
2. `WORLD.md`、`CHARACTERS.md`、`chatgpt/PROMPT.md` を編集する。
3. 必要なら `assets/` にキャラクター画像を追加する。
4. ChatGPTへ自分のリポジトリURLと次の指示を送る。

```text
このリポジトリの最新版を読んで、この設定に沿ってキャラクターとして会話して。
WORLD.md、CHARACTERS.md、chatgpt/PROMPT.md を優先して参照して。
assets/ にキャラクター画像がある場合は、それも外見の参考資料として確認して。
```

設定を更新した後は、必要に応じて次のように伝えます。

```text
リポジトリを更新したので最新版を読み直して。
```

### 方法B：ファイル直接型

GitHubを使わずに始めたい人向けです。PCやスマートフォンからファイルをChatGPTへアップロードするだけで使えます。

新しいチャットに、次のファイルをまとめてアップロードします。

```text
WORLD.md
CHARACTERS.md
chatgpt/PROMPT.md
assets/ 内の画像（使う場合）
```

その後、次のように伝えます。

```text
アップロードした WORLD.md、CHARACTERS.md、chatgpt/PROMPT.md を読んで、この設定に沿ってキャラクターとして会話して。
画像ファイルがある場合は、キャラクターの外見の参考資料として使って。
```

GitHubの操作やアカウントは必要ありません。

### どちらを使えばいい？

- とりあえず試したい → **ファイル直接型**
- GitHubを使ったことがない → **ファイル直接型**
- 設定を頻繁に更新する → **GitHub参照型**
- 複数人で設定を管理する → **GitHub参照型**
- 公開配布したい → どちらでも可。配布用ZIPとGitHubを両方用意してもよい

どちらの方法でも、設定ファイルの中身は同じです。

## ファイル構成

```text
.
├── README.md
├── WORLD.md
├── CHARACTERS.md
├── TEMPLATE_GUIDE.md
├── assets/
│   ├── README.md
│   ├── character-a.png
│   └── character-b.png
└── chatgpt/
    └── PROMPT.md
```

設定とAIへの演技指示を分離することで、設定変更と会話調整を別々に行えます。

## 何をどこに書くか

### WORLD.md

キャラクター個人ではなく、世界そのものに属する設定を書きます。

例：

- 舞台
- 時代
- 世界の法則
- 住んでいる場所
- 日常
- 能力の共通ルール
- 登場してよい存在
- 勝手に追加してほしくないもの

### CHARACTERS.md

各キャラクターに属する設定を書きます。

例：

- 名前
- 外見
- 性格
- 一人称
- 口調
- 好き嫌い
- 知識量
- 他キャラクターとの関係
- やること / やらないこと

### assets/

キャラクターの外見やデザインを画像で指定したい場合に使います。

例：

- `assets/character-a.png`
- `assets/character-b.png`
- 表情差分や衣装差分など

画像を置いた場合は、`CHARACTERS.md` から対応する画像パスを明記してください。ChatGPTが画像を参照できる環境では、文章設定と合わせて外見の参考資料として扱えます。

画像は口調や性格を決めるものではなく、主に外見・色・形・服装などの視覚資料として扱います。文章設定と画像が食い違う場合にどちらを優先するかも、必要なら `CHARACTERS.md` に明記してください。

### chatgpt/PROMPT.md

設定そのものではなく、「ChatGPTにどう演じてほしいか」を書きます。

例：

- 返答の長さ
- 地の文の量
- 一度に何人しゃべるか
- キャラクター外の説明をするか
- 知らないことへの反応
- 会話中に勝手な新設定を作らない
- リセットなどの特殊コマンド

## 大事な考え方

**設定と演技指示を混ぜすぎない**のがコツです。

たとえば「このキャラクターは猫が好き」は `CHARACTERS.md` に書きます。

「猫の話題を毎回無理に出さない」は `chatgpt/PROMPT.md` に書きます。

「この世界には猫が存在しない」は `WORLD.md` に書きます。

この分け方にすると、設定が増えても矛盾を見つけやすくなります。

## GitHub参照時の注意

ChatGPTや利用環境によっては、GitHubリンクを自動で読めない場合があります。その場合は、方法Bの「ファイル直接型」を使ってください。

また、GitHub側を更新しても、すでに進行中の会話へ自動反映されるとは限りません。更新後は最新版の再読込を指示してください。

## 次にやること

`TEMPLATE_GUIDE.md` を見ながら、`WORLD.md`、`CHARACTERS.md`、`chatgpt/PROMPT.md` の `[ ]` 部分を書き換えてください。

不要な項目は削除して構いません。重要なのは、AIが推測しなくてもキャラクターの振る舞いを判断できる程度に、必要なルールを明示することです。
